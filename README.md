## Configuring the PATH environment variable ##
```bash
To configure your current shell, run:
$ source "$HOME/.cargo/env"
$ export PATH=$PATH:~/.cargo/bin
$ export PATH=$PATH:$HOME/.cargo/bin
```

$ rustc --version
